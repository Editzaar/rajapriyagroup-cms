# 🚀 Raja Priya Group — AI Blogger CMS Cloud Platform

A Vercel-ready **AI Content Management System (CMS)** web application built for **Raja Priya Group**.

---

## 🌟 How It Works

1. Open the live Vercel URL on any mobile device or computer.
2. Enter an article **Topic** or brief **Summary**.
3. Click **"⚡ Generate AI Article & Cover"**.
4. Review the AI-generated title, category tags (`Real Estate`, `Video Editing`, `Web Dev`, `Brand Growth`), cover graphic, and HTML body on the live Apple Frosted Glass Canvas.
5. Click **"🚀 Approve & Publish to Blogger"** to confirm and post directly!

---

## 🌐 1-Click Vercel Deployment Instructions

### Method A: Deploy via GitHub + Vercel Dashboard (Recommended)
1. Create a new repository on your GitHub account named `rajapriyagroup-cms`.
2. Push this folder to GitHub:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/rajapriyagroup-cms.git
   git branch -M main
   git push -u origin main
   ```
3. Go to [Vercel.com](https://vercel.com) -> Click **"Add New Project"**.
4. Select `rajapriyagroup-cms` from GitHub -> Click **Deploy**!

### Method B: Deploy via Vercel CLI
Run the following command inside this folder:
```bash
npx vercel
```

Vercel will provide your live URL (e.g. `https://rajapriyagroup-cms.vercel.app`) instantly!
